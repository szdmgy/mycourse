# 实验报告收集系统 — 教师使用说明

> 面向教师用户的简易操作指南

---

## 一、登录与入口

1. 打开系统地址（如 `http://服务器IP:9900` 或 `http://服务器IP:8001`）
2. 使用工号及密码登录
3. 登录后进入**我的课程**，顶部导航包含：课程列表、个人信息、注销

---

## 二、课程管理

### 2.1 我的课程

- 按学期分组显示您任教的课程
- 点击课程卡片进入**课程详情**（含作业管理、提交统计、学生管理三个 Tab）
- 若没有课程，需先导入

### 2.2 导入课程

1. 在课程列表页点击右上角「导入课程」
2. 选择从学校教务系统导出的课程 Excel 文件（深大成绩登记表格式）
3. 点击「预览导入」→ 系统解析并显示课程信息、教师、学生名单及状态
4. 确认无误后点击「确认导入」写入系统
5. 只能导入您本人任教的课程
6. 可先下载「课程导入模板.xlsx」了解格式

---

## 三、课程详情（三个 Tab）

### Tab 1：作业管理

**添加作业：**

1. 点击「添加作业」
2. 填写：作业标题、作业正文、截止日期、允许的文件类型（如 `.docx,.pdf` 或 `*` 不限）
3. 提交后作业会出现在列表中

**从历史复用：**

1. 点击「从历史复用」
2. 选择历史班级（含往届同名课程）
3. 勾选要复用的实验（标「含模板」会复制报告模板；标「含预检」会复制作业级预检配置与规则包）
4. 点击「导入到当前课程」
5. 标题冲突时会自动追加「(副本)」
6. 预检若为「继承课程」，复用后仍跟随**当前课程**总开关；显式模式与框架规则包会原样带入

**导入作业（Excel）：**

1. 点击「导入作业」
2. 上传 Excel 文件（格式：标题 | 内容 | 文件类型 | 显示）
3. 预览后确认导入
4. 可下载「作业导入模板.xlsx」

**其他操作：**

- **编辑**：修改作业内容、截止日期、是否显示、文件类型
- **作业记录**：查看该作业的提交详情
- **删除**：删除作业及所有提交记录（需二次确认）

---

### Tab 2：提交统计

- 每个作业以折叠面板展示：已交人数 / 未交人数
- 展开后可查看：
  - **已提交列表**：学号、姓名、性别、提交时间、附件状态、是否延期
  - **未提交列表**：学号、姓名、性别
- 勾选已提交学生后，点击「下载选中作业」可批量下载（ZIP 打包）
- 底部有「查看异常作业记录」入口，可查看延期提交、未提交记录

---

### Tab 3：学生管理

**添加学生：**

1. 点击「添加学生」展开表单
2. 填写学号、姓名、性别
3. 提交后学生加入课程

**其他操作：**

- **重置密码**：将学生密码重置为默认（`szu` + 学号后六位）
- **移除**：将学生移出课程（需二次确认）

**批量导入学生：**

- 在课程导入时，Excel 中已包含学生名单；或通过管理员导入
- 教师可单独添加遗漏学生

---

## 四、作业记录与异常记录

### 作业记录

- 从作业管理 Tab 点击某作业的「作业记录」进入
- 显示未提交学生、已提交学生（含提交时间、附件、延期状态、预检警告等）
- 可勾选已提交学生，批量下载作业；支持附件在线预览（可预览格式）
- 顶栏可查看批改进度；可用筛选：未批改 / 不合格(F) / 待重评 / 预检警告

### 定性批改与参考分

在「已提交学生」表格中逐行批改：

| 项 | 说明 |
|----|------|
| 等级 | 必选：A+ / A / B / C / D / F（不合格） |
| 参考分 | **可选**，0–100 整数；填在等级旁窄框（占位「分」） |
| 评语 | 可选文字说明 |
| 保存 | 单行「保存」，或勾选多行后用「保存全部修改」 |

**参考分约定：**

- 仅为教师侧备注，**不替代等级**，不参与不合格判定
- **不向学生展示**（学生端仅在等级为 F 时看到「不合格」及相关提示）
- 可与等级并存且允许不一致（例如等级 B、参考分 78）
- 清空输入框后保存，即清除该生参考分

**不合格（F）与重交：**

- 评为 F 后，学生端会提示需重交；学生重新提交后标记为「待重评」
- 教师再次保存等级后清除「待重评」

**成绩汇总：**

- 作业记录页进入「成绩汇总」：按等级看人数分布与名单（占比分母为应交总人数）
- 「导出 Excel」→ 明细表含：学号、姓名、等级、**参考分**、评语、待重评

### 异常作业记录

- 从提交统计 Tab 底部点击「查看异常作业记录」
- 显示延期提交、未提交的学生列表
- 支持导出 Excel

---

## 五、个人信息与密码

- **个人信息**：顶部导航「个人信息」可修改邮箱、手机号
- **修改密码**：在个人信息页底部有「修改登录密码」入口

---

## 六、常见问题

| 问题 | 处理方式 |
|------|----------|
| 导入课程失败 | 检查 Excel 格式是否符合深大成绩登记表；确认课程是否已存在 |
| 学生看不到作业 | 检查作业是否「显示」；检查学生是否在课程名单中 |
| 批量下载无反应 | 确认已勾选至少一名学生 |
| 参考分保存失败 | 须为 0–100 的整数；可留空表示不填/清除 |
| 学生看不到等级（非 F） | 正常：当前仅 F（不合格）对学生可见 |
| 忘记密码 | 联系管理员重置 |

---

## 七、Excel 格式说明

### 课程导入

- 按深圳大学学生成绩登记表格式
- 关键单元格：A3 学期、C5 课程编号、F5 班号、R5 课程名、K6 教师、第 10 行起 B/C/D 列学号/姓名/性别

### 作业导入

- 列：标题 | 内容 | 文件类型（可选，`*` 不限） | 显示（Y/N，可选）
- 截止日期自动设为导入日 + 120 天
