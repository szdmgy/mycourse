## 2026-04-27 合订说明

### 1. 参考资料（课程级静态文件）

- **模型**：`app01.ReferenceMaterial`，字段含课程、标题、说明、`filePath`、`originalName`、`file_size`、`sort_order`、`display`、上传者、时间戳。
- **存储路径**：`file/<学期>/<课程名+班号>/参考资料/`，与作业目录同树；**磁盘文件名与上传 basename 一致**，不自动加随机后缀。
- **校验（预检）**：文件名非法（含 `<>:"|?*/\`、路径分隔符、Windows 保留名等）或**本课程内同名文件（忽略大小写）**或目录已存在同名物理文件时，**拒绝上传/不入库**。
- **教师端**：课程详情 Tab「参考资料」— 上传、编辑（可换文件）、删除、下载、**上移/下移**排序；**从同名课程其他学期/班级复制**（含磁盘文件副本，权限对齐 `getHistoryTasks`）。
- **学生端**：「我的课程 → 课程」Tab「参考资料」，仅见 `display=True` 的条目，可下载。
- **权限**：`can_manage_course`（管理员任意课程；教师须为课程 `members`）；下载按角色校验。
- **迁移**：`0003_reference_material.py`、`0004_reference_material_sort_order.py`。

### 2. 作业相关 URL 修复

- `taskSubmit`、`homeworkRecords`、`taskChange` 路由**仅保留 `taskID`**，不再把作业标题拼进 URL，避免标题含 `/` 等导致路由错误。
- 模板中 `{% url %}` 已同步调整。

### 3. Windows 部署/升级脚本（对齐 expense_log / 全局 Y12）

- 根目录 **`mycourse_deploy_update.bat`**：首次克隆 + `venv` + 依赖；二次运行检查 `.env` 与 `db.sqlite3` 后 **`git pull --ff-only`**、依赖、`migrate`、`collectstatic`。
- 适配本仓库 **Git 根目录与 `manage.py` 分离**（`mycourse/mycourse/`）。
- **`mycourse/mycourse/.env.example`**：占位说明；升级时若无 `.env` 可尝试从示例复制。
- 文档：**`docs/服务器部署升级速查.md`**；**`README.md`** 增加部署/升级说明。
