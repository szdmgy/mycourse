# 参考资料 — 功能需求文档

> 文档版本：v1.1  
> 日期：2026-04-26  
> 状态：已落地（教师/学生端 Tab、存储、复制、排序等已在代码中实现）  
> 关联：与主文档《需求文档.md》中课程、作业、权限原则保持一致；存储规则与现有**学生作业上传路径**对齐。

---

## 一、背景与目标

### 1.1 背景

教师在课程详情中除「作业管理」外，需要集中提供**可供学生下载**的静态资料（课件、视频、实验指导书、压缩包、实验模板等）。**早期曾在页面中放过纯前端演示表格行，已在接入数据库与上传功能时全部删除**；列表数据一律来自 `ReferenceMaterial` 与磁盘文件。本文档描述产品规则与验收要点。

### 1.2 目标

1. 教师（及管理员）可按**学期 + 课程 + 班级**隔离地维护参考资料；学生仅能看到**已发布**条目并下载。  
2. 文件落盘规则与**实验报告/作业**使用同一套目录树，便于备份与运维。  
3. 支持从**同名课程**的其他学期/其他班级**复制**参考资料到当前课程，交互与权限与现有**作业「从历史复用」**对齐，降低跨年、平行班重复上传成本。

---

## 二、术语

| 术语 | 含义 |
|------|------|
| 当前课程 | 教师正在打开的课程详情所对应的 `Course` 记录。 |
| 同名课程 | `courseName` 与当前课程相同、且**不是**当前课程主键的其他 `Course` 记录（可跨 `courseTerm`、`classNumber`）。 |
| 参考资料根目录 | 相对于项目 `BASE_DIR`，位于 `file/<学期>/<课程名+班号>/参考资料/` 的目录（见第四节）。 |
| 发布/显示 | 教师在资料上设置「对学生显示」；关闭时学生端**不展示该条**（与作业 `display` 语义一致）。 |

---

## 三、角色与权限

| 能力 | 管理员 | 教师 | 学生 |
|------|--------|------|------|
| 查看本课程参考资料列表（教师端列含隐藏项） | ✅ | ✅（仅自己负责的课程范围，与现有课程权限一致） | ❌ |
| 查看已发布参考资料列表 | ✅ | ✅ | ✅（仅已加入该课程的学生） |
| 上传 / 编辑 / 删除 / 更换文件 | ✅ | ✅（仅自己的课程） | ❌ |
| 从同名课程复制参考资料到当前课程 | ✅（可浏览系统中同名课程） | ✅（仅自己能访问的同名课程，规则对齐 `getHistoryTasks`） | ❌ |
| 下载文件 | ✅ | ✅ | ✅（仅已发布条目，且已选课） |

**原则**：管理员权限 ≥ 教师；跨课程操作时与现有「历史实验复用」一致。

## 四、文件存储与隔离（与作业对齐）

### 4.1 路径约定

与现有学生作业上传逻辑一致（见 `post_file`），参考资料**不**单独使用新的配置根目录，仍基于 `BASE_DIR` 拼接：

- **作业/报告**目录：`file/<courseTerm>/<courseName><classNumber>/<safe_filename(作业标题)>/`  
- **参考资料**目录：在同一「课程+班」层级下增加固定子目录 **`参考资料`**：

```text
file/<courseTerm>/<courseName><classNumber>/参考资料/<存储用文件名>
```

说明：

- `<courseName><classNumber>` 与代码中现有拼接方式一致（两字段直接拼接，无额外分隔符）。  
- 目录名使用中文 **`参考资料`**，与产品文案一致。  
- **首次**向该课程写入任意参考资料时，若目录不存在则创建（`exist_ok=True`）。

### 4.2 数据库中路径建议

- 存**相对 `BASE_DIR` 的路径**（与 `HomeworkFile.filePath` 一致），便于迁移与 `absPath` 类逻辑复用。  
- 原始上传文件名、展示标题、说明、是否显示、上传者、上传时间等由模型字段承载（具体表结构在详细设计阶段定）。

### 4.3 文件约束

| 项 | 规则 |
|----|------|
| 单文件大小上限 | **100 MB**；前后端均需校验，超限拒绝并明确提示。 |
| 资料类型 | **不**做业务上的类型枚举；以标题与文件名为准。 |
| 压缩包 | 允许 zip/rar 等；**不对包内文件做格式校验**（信任教师上传）。 |
| 更换文件 | 允许编辑时替换附件；删除资料时建议删除磁盘文件（与作业删除策略对齐，详细设计阶段定）。 |

## 五、功能需求 — 教师端（课程详情 · 参考资料 Tab）

### 5.1 列表

- 表格列建议：**序号、标题、文件名（或存储名）、大小、上传时间、显示（显示/隐藏）、操作（编辑、下载、删除）**。  
- 列表仅展示**本课程**下的参考资料。  
- 「隐藏」条目在教师端仍显示，便于管理；学生端不显示（见 5.5）。

### 5.2 上传

- 必填：**标题**、**附件**。  
- 选填：**说明**（可仅在详情/编辑弹窗中展示，列表是否展示由实现决定）。  
- 默认 **对学生显示**；可关闭。  
- 上传成功后文件写入第四节路径；数据库新增记录。

### 5.3 编辑

- 可修改：标题、说明、是否显示。  
- **允许更换文件**；未选择新文件则保留原文件。更换后更新大小、上传时间（或单独「更新时间」字段，由详细设计定）。

### 5.4 删除

- 二次确认；删除记录并删除对应磁盘文件（若采用软删除需在详细设计中单独说明）。

### 5.5 下载（教师/管理员）

- 鉴权：与下载作业类似，仅本课程教师/管理员或规则允许的角色可下载；链接防直链滥用（会话/权限校验）。

## 六、功能需求 — 学生端

- 在**我的课程 → 进入课程**后提供「参考资料」入口（与教师端 Tab 名称一致：**参考资料**）。  
- 仅展示 **「对学生显示」** 的条目；**隐藏**条目不出现在列表中。  
- 操作：**下载**（及必要的文件名校验/防遍历）。  
- **无**上传、编辑、删除、复制入口。

---

## 七、从同名课程复制参考资料（与作业复用对齐）

### 7.1 业务含义

支持将**其他学期、其他班号**但**课程名相同**的历史课程中的参考资料，复制到**当前课程**，避免重复上传。与「作业管理 → 从历史复用」在**课程匹配维度**上保持一致：**按 `courseName` 匹配**，不包含当前课程自身。

### 7.2 权限与数据范围（对齐现有作业 API）

与 `getHistoryTasks` 一致：

- **管理员**：可列出系统中所有与当前课程 `courseName` 相同、且 `pk ≠ 当前课程` 的课程及其参考资料。  
- **教师**：仅列出自己作为成员（`members`）的、同名且非当前的课程及其参考资料。

若系统中无符合条件的源课程或无资料，界面给出明确空状态提示。

### 7.3 交互建议（产品层）

- 在参考资料 Tab 提供按钮，例如：**从其他学期/班级复制**（文案可再缩短），交互可参考「从历史复用」：**先选来源课程（展示学期 + 班号）→ 再勾选多条资料 → 确认复制**。  
- 对已在当前课程**标题相同**（或「标题 + 文件名」冲突，规则在详细设计中二选一）的条目，界面标注 **已存在** 或自动跳过，避免误复制（与作业复用中 `duplicate` 提示类似）。

### 7.4 复制行为（技术约束）

- **物理文件**：从源路径 `file/<源学期>/<源课程名+源班号>/参考资料/` **复制**到当前课程的 `参考资料/` 目录下；**不得**仅依赖数据库指向同一磁盘路径（避免删除源课程时影响目标课程）。  
- 新文件命名需避免覆盖：可使用时间戳/UUID 前缀或安全规则生成存储名；**展示标题**可与源一致或由教师确认后写入。  
- 复制后的记录归属**目标课程**；默认 **对学生显示** 可与源一致或由界面勾选（建议默认与源一致，可在详细设计中定）。  
- 单条资料大小仍受 **100 MB** 限制；批量复制时若某条失败应明确提示哪几条失败。

### 7.5 与作业复用的差异（说明）

| 维度 | 作业「从历史复用」 | 参考资料复制 |
|------|-------------------|--------------|
| 匹配键 | 同名课程 | 同名课程（一致） |
| 复制对象 | `Task` 元数据（无学生文件） | 元数据 + **磁盘文件** |
| 冲突处理 | 标题重复标记 / 导入后加「(副本)」等 | 需定义标题或文件级冲突策略 |

## 八、非功能与安全

| 项 | 要求 |
|----|------|
| 路径安全 | 展示标题、说明需防 XSS；存储文件名防路径穿越；`safe_filename` 等与作业一致。 |
| 传输 | 局域网环境；大文件上传可考虑超时与服务器限制配置说明写入运维文档。 |
| 审计（可选） | 记录上传/删除/复制操作人及时间，便于追溯。 |
| 离线前端 | 不引入外网 CDN；与主需求文档一致。 |

## 九、验收要点（摘要）

1. 同一课程下参考资料增删改查、显示/隐藏、下载符合第三节权限。  
2. 磁盘路径符合第四节，且与现有作业目录在同一 `file/<学期>/<课程名+班号>/` 树下。  
3. 单文件 >100MB 被拒绝；压缩包可上传且包内不校验。  
4. 学生端看不到隐藏条目；教师端可管理隐藏条目。  
5. 同名课程复制：权限范围与作业历史复用一致；复制后目标课程磁盘上存在独立文件副本；冲突与失败提示清晰。
