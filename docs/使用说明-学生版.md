# 实验报告收集系统 — 学生使用说明

> 面向学生用户的简易操作指南

---

## 一、登录

1. 打开系统地址（如 `http://服务器IP:9900` 或 `http://服务器IP:8001`）
2. 输入**用户名**（学号）和**密码**
3. 默认密码：`szu` + 学号后六位（如学号 2023222001，密码为 `szu222001`）
4. **首次登录**会强制跳转到修改密码页，请先修改密码后再使用

---

## 二、我的课程

登录后进入**我的课程**页面，按学期分组显示你已加入的课程。

- 点击课程卡片进入该课程的**作业列表**
- 若没有课程，请联系老师导入名单

---

## 三、作业列表

进入课程后，可看到该课程下所有作业，包括：

| 列 | 说明 |
|----|------|
| 作业名称 | 实验/作业标题 |
| 截止日期 | 提交截止时间 |
| 提交状态 | 已提交 / 未提交 / 逾期提交 / 逾期未提交 |
| 提交时间 | 最近一次提交时间 |
| 操作 | 点击「提交」进入提交页面 |

**状态说明：**

- 已提交：截止前已提交
- 未提交：截止日期内，尚未提交
- 逾期提交：超过截止日期才提交
- 逾期未提交：超过截止日期且未提交

---

## 四、提交作业

1. 在作业列表中点击某作业的「提交」按钮
2. 查看作业详情（标题、内容、截止日期、允许的文件类型）
3. 在「附件上传」区域：
   - 点击「选择文件」选择要上传的文件
   - 点击「上传」完成提交
4. 上传成功后，可点击文件名下载已上传的文件
5. **重新上传会覆盖**之前的文件，请确认后再操作

**注意：**

- 文件类型需符合老师设置（如 `.docx`、`.pdf` 等，`*` 表示不限）；旧版 `.doc` 不可用，请用 `.docx`
- 若老师启用了报告预检，提交时可能先检查封面/框架；「硬拦截」须改对后才能提交，「仅警告」可确认后仍提交
- 建议文件名包含学号、姓名，便于老师批阅
- 部分作业可下载报告模板（封面字段可能自动带入课程/个人信息）

---

## 五、成绩与不合格提示

- 老师批改以**等级**为主（A+～D、F）；若老师另记了参考分数，**学生端不会显示**该分数
- **仅当等级为不合格（F）时**，作业列表会显示不合格相关提示与评语（如有）
- 被评为 F 后请按老师要求修改并**重新提交**；重交后一般显示「已重交·待重评」，等待老师再次批改

---

## 六、个人信息与密码

- **个人信息**：顶部导航「个人信息」可修改邮箱、手机号
- **修改密码**：在个人信息页底部有「修改登录密码」入口，可随时修改

---

## 七、常见问题

| 问题 | 处理方式 |
|------|----------|
| 忘记密码 | 联系任课老师重置 |
| 没有课程 | 联系老师确认是否已导入名单 |
| 上传失败 | 检查文件格式是否符合要求（如 .docx、.pdf）；旧版 .doc 请另存为 .docx |
| 预检未通过 | 按页面提示修改封面/框架后重传；警告模式可确认后仍提交 |
| 看不到自己的分数/等级 | 非不合格时通常不展示；仅 F 会提示，具体以老师说明为准 |
| 找不到作业 | 确认老师是否已发布（显示）该作业 |

---

*如有其他问题，请联系任课教师或管理员。*
